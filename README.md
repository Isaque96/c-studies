# ESTUDOS

## COMANDOS

* Para rodar o jogo Foge-Foge `gcc fogefoge.c mapa.c ui.c -o fogefoge.exe` para **Windows** ou `gcc fogefoge.c mapa.c ui.c -o fogefoge.out` para **Linux**
* Para rodar o jogo da Forca `gcc forca.c forca.exe` para **Windows** ou `gcc forca.c forca.out` para **Linux**
* Para rodar os estudos de ponteiro `gcc ponteiro.c ponteiro.exe` para **Windows** ou `gcc ponteiro.c ponteiro.out` para **Linux**
